# tuana0410.github.io

My personal portfolio, styled like a small retro desktop: each section is a window you can minimize, and the desktop icons work as navigation.

**Live:** https://tuana0410.github.io

## What's inside

- **about.txt** – who I am and how to reach me
- **experience** – internship and team work
- **projects** – software and R&D projects, filterable by type, with live and repo links where they exist
- **lab** – a prompt benchmark across text, image and video models, and an open-source fix I contributed
- **skills.exe** – languages, frameworks and tools
- **terminal.exe** – a small terminal; type `help` to see the commands

## Built with

- Plain HTML, CSS and JavaScript, no framework or build step
- Self-hosted fonts (Silkscreen, Space Mono) with Turkish characters
- Works on phones: the layout switches to one column under 720 px

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000   # then open http://localhost:8000
```

Deployed with GitHub Pages from the `main` branch.
